# Theming spike checks

Passed for the exercised theme mechanism, four themes and both workflows. The [accepted decisions](../../planning.md#theming-decisions-accepted-on-2026-10-28) call for Paper as the lead second theme (light-only), a workflow default overridable by a personal setting, tokens plus scoped structural rules, bundled open-licence fonts, a refreshed first theme, and untouched previews. **Visual quality is the user's call; these checks do not establish acceptance of any theme.**

## Build and scope

The [manifest](../../evidence/2026-10-28-theming/manifest.json) records Git base `d402fae`, hashes of every changed source, theme and font file, Node v22.19.0, Chrome 156 and the installed Fungi `v0.1.0-alpha.2` binary. The source tree also contains the uncommitted shared-UI extraction this spike builds on.

Browser drivers use headless Chromium with an injected public page bridge. The native driver opens one isolated synthetic session per theme, whose fixture submits its own measurements. No human session was touched.

## Corrections during the run

- **First theme run:** the contrast gate failed muted text in Mono (3.54:1) and Paper (4.42:1) and Neutral's focus ring (2.56:1). The tokens were darkened and the run passed.
- **Mono code blocks:** inline-code borders also boxed the code inside `pre`; the rule now excludes it.
- **Expand button:** in Paper and Neutral, theme-level button padding collapsed the expand icon. Padding became the `--ui-button-padding` token, and the driver now fails on collapsed icon buttons.

## Limits

- Sandboxed previews appear blank in the theme driver's full-page screenshots; the gallery driver, which interacts with the frame, shows the preview rendering.
- Templates still declare `color-scheme: dark`, so a light theme may briefly show a dark canvas before its CSS loads. This has not been measured natively.
- Region-comment and image-preview dialogs are styled only through tokens; they were not opened under the light themes.
- Windows/Linux font fallback and a fresh human review of the themed pages remain outside this run.
