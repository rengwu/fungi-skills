# Shared UI extraction checks

Passed for the exercised [shared UI kit](../../features/fungi-ui.md), [grill-form](../../features/grill-form.md) and [outcome](../../features/show-outcome.md) behavior. The [accepted decisions](../../planning.md#shared-ui-decisions-accepted-on-2026-10-28) require all existing UI components, free workflow composition/style overrides, inline image Notes, runtime assemblers and kit-first reusable controls.

## Build and scope

The [manifest](../../evidence/2026-10-28-ui-kit/manifest.json) records Git base `d402fae`, dirty-source hashes, Node/macOS identity and the installed Fungi `v0.1.0-alpha.2` binary. Source already contained the earlier next-step, recommendation and delivery changes; the extraction preserves those behaviors.

Shared source now lives in `skills/fungi-ui/`. Workflow HTML/modules compose it; their models and result schemas remain independent. Assemblers copy source and input into a fresh retained bundle. One maintained vendor directory supplies both workflows. Ignored local compatibility subtrees keep earlier direct-source page paths usable and are excluded from new assemblies. Human session storage was not modified.

Native drivers assemble isolated synthetic bundles, remove the callback target and use one bounded `wait` per session. Browser drivers use headless Chromium and an injected public page bridge. No synthetic answers were sent to a human session.

## Fixture corrections

The first native outcome attempt checked the error node before module initialization created it. The driver now waits for that node; this was a test timing issue, not missing error UI. Its [failure record](../../evidence/2026-10-28-ui-kit/outcome-native-attempt1.json) is retained.

The first gallery attempt supplied a combined key name unsupported by Puppeteer's keyboard API. The second sent separate Meta/Z events, but the headless browser did not invoke undo through that shortcut. The final check invokes the browser's actual undo command and confirms the chip and its submitted artifact return. These are recorded as [attempt one](../../evidence/2026-10-28-ui-kit/gallery-attempt1.json) and [attempt two](../../evidence/2026-10-28-ui-kit/gallery-attempt2.json); OS keyboard-shortcut behavior is not claimed.

## Limits

Native checks establish public page/API behavior on the installed macOS runtime, including real iframe region capture. Synthetic clipboard events do not establish physical clipboard behavior. Browser failure injection does not establish native engine failure recovery. The undo command passed; physical keyboard shortcuts remain untested. Long idle/sleep, Windows/Linux and fresh human usability with the assembled pages remain outside this run.

The preparation interview used the earlier page, received a real Codex callback and was collected once. No fresh callback or Claude background completion is claimed for the extracted UI. Source schemas remain compatible with earlier report drafts, but arbitrary historical direct-source sessions were not reopened during this check. Their storage and local compatibility assets are retained.
