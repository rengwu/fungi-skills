## Limits and follow-up

This run does not verify human usability, native callback/manual return of this new flow, physical clipboard interaction, OS window-close recovery, prolonged reading/sleep, or Windows/Linux. The browser retry test uses a test double for failed API calls; it does not establish native failure recovery. The native Close button exercises cancellation plus explicit reopening, not the OS window close control.

The development shell still cannot resolve `fungi` on PATH. That blocks normal invocation under the shared skill's accepted gate; absolute binary execution here is an explicit development test, not a runtime workaround. A fresh agent independently observed that gate. A human trial can begin once the user's agent environment exposes `fungi` normally. There is no change to global activation settings or Fungi delivery machinery.
